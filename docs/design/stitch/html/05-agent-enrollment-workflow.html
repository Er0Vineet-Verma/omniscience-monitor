memory Under the Hood

Omniscience utilizes a hardened internal PKI infrastructure backed by BouncyCastle for the embedded CA. Every agent establishes an outbound mTLS tunnel, ensuring cryptographic tenancy resolution and preventing lateral data exfiltration.

shield_locked
Tenancy is strictly resolved via the Common Name (CN) verified against the mTLS client cert. API requests lacking valid client certificates are dropped at the ingress controller.
